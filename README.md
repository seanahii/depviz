# depviz — визуализатор графа зависимостей пакетов Python

Практическая работа №2 по дисциплине «Конфигурационное управление», вариант 28.
Выполнил: Царев А.А., ИКБО-66-25.

## Общее описание

`depviz` — CLI-приложение, которое строит граф зависимостей пакетов
Python (pip). Готовые менеджеры пакетов и библиотеки для получения
зависимостей не используются — только стандартная библиотека Python.

Текущий этап: **2 — сбор данных**.

## Как получаются зависимости

Данные берутся из JSON API репозитория PyPI:
`<repo>/<пакет>/<версия>/json`, например
`https://pypi.org/pypi/requests/2.31.0/json`. Из поля
`info.requires_dist` (строки формата PEP 508) извлекаются имена
зависимостей, ограничения версий и маркеры окружения. Зависимости
с маркером `extra == "..."` — необязательные группы (`pip install
pkg[extra]`) — не учитываются, так как pip не ставит их по умолчанию.
Имена нормализуются по PEP 503 (`Foo_Bar` → `foo-bar`).

## Параметры (опции командной строки)

| Опция | Описание |
|-------|----------|
| `-p`, `--package` | имя анализируемого пакета (обязательно) |
| `-r`, `--repo` | URL репозитория или путь к файлу тестового репозитория (обязательно) |
| `-m`, `--mode` | режим работы с репозиторием: `real` (по умолчанию) или `test` |
| `-v`, `--version` | версия пакета (обязательна в режиме `real`) |
| `-f`, `--filter` | подстрока для фильтрации пакетов |

Проверки параметров:

- `--mode` — только `real` или `test`;
- `--package` — не пустое; в режиме `real` — допустимое имя пакета Python,
  в режиме `test` — только большие латинские буквы;
- `--repo` — в режиме `real` URL вида `http(s)://хост/путь`,
  в режиме `test` — существующий файл;
- `--version` — формат версии PEP 440 (например `2.31.0`, `1.0rc1`);
- `--filter` — непустая строка без пробелов.

При ошибке выводится сообщение `Ошибка: ...` в stderr и код возврата 1.

## Сборка и тесты

Сторонние зависимости не нужны, достаточно Python 3.10+.

```sh
make test          # запуск тестов
./run.sh --help    # справка
```

## Примеры

Прямые зависимости `requests` 2.31.0:

```text
$ ./run.sh -p requests -r https://pypi.org/pypi -v 2.31.0
Прямые зависимости requests==2.31.0:
  charset-normalizer (<4,>=2)
  idna (<4,>=2.5)
  urllib3 (<3,>=1.21.1)
  certifi (>=2017.4.17)
```

Ошибки:

```text
$ ./run.sh -p requests -r https://pypi.org/pypi -v 0.0.0
Ошибка: не найдено в репозитории: https://pypi.org/pypi/requests/0.0.0/json

$ ./run.sh -p requests -r pypi.org -v 2.31.0
Ошибка: некорректный URL репозитория 'pypi.org', ожидается http(s)://хост/путь
```
